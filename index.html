Senryaku Kigyo Uploader

A personal, single-user automation tool for publishing videos to one YouTube channel.

What this application is

Senryaku Kigyo Uploader is a private automation tool developed and operated by the owner of the YouTube channel 戦略で読む企業史 (@senryaku-kigyo). The channel publishes long-form commentary videos about corporate history. The tool uploads the owner's own finished video files to his own channel so that routine publishing steps do not have to be repeated by hand in YouTube Studio.

The application is used by exactly one person: the developer himself, on his own computer, with his own Google account. It is not distributed to anyone, it has no sign-up, and no other user can authorize it or use it.

How the YouTube upload scope is used

The application requests a single OAuth scope, https://www.googleapis.com/auth/youtube.upload, and uses it only to:

  • upload video files to the owner's own YouTube channel (YouTube Data API videos.insert),
  • set the title, description, and scheduled publication time of those uploaded videos, and
  • set the custom thumbnail of those uploaded videos (thumbnails.set).

The application does not read, modify, or delete any other content, and it does not access data belonging to any person other than the operator himself. No other Google API scopes are requested.
